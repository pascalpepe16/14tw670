RADIO AMATEUR GROUP - PORTAIL V1

Version avec fond radio personnalisé.

Fichier principal : index.html
Style : style.css
Script : script.js

Fond d'écran : images/fond-radio.jpg

Le fond est appliqué à tout le site avec une légère couche sombre pour garder le texte lisible.
Les cartes et sections sont semi-transparentes afin de laisser apparaître l'image.

Le site reste statique : les fonctions eQSL, membres, logs, etc. sont des interfaces prêtes à être reliées à un serveur/base de données.
